# 릴스 → 기획 분석 아카이브 + CapCut 교체형 템플릿

공개 Instagram 릴스의 **편집 문법**을 분석해, 영상과 문구만 바꿔 쓸 수 있는
CapCut 템플릿 초안을 만드는 macOS 로컬 앱입니다. 단순 분석 보고서가 아니라
레퍼런스의 컷 타이밍·강조 자막·펀치 줌·오버레이·효과음 자리를 실제 트랙으로 만듭니다.
동시에 공개 본문·반응 지표·댓글과 영상 대본을 결합해 시의성·3초 후킹·이탈방지·CTA·
사랑받은 포인트를 분석하고 로컬 `기획분석_아카이브`와 Obsidian 세컨드 브레인에
계속 축적합니다.

## 만드는 결과

- `말 자막.srt` — 로컬 Whisper large-v3 받아쓰기
- `분석결과.json` — 장면 전환, 화면 효과, 자막 스타일, 효과음 후보, 화면 글자
- `기획분석.md` — 주제 시의성, 3초 후킹, 이탈방지, CTA, 댓글 반응 인사이트
- `편집가이드.md` — 타임코드별 편집 재료와 주의사항
- `초안-원본-의존관계.json` — 삭제하면 깨지는 연결 파일 안내
- CapCut 초안
  - `교체할 영상 · 템플릿` — 레퍼런스 컷 분할과 실제 로컬 CapCut 줌 애니메이션이 적용된 주 영상
  - `말 자막` — 레퍼런스 위치·색·크기를 반영한 일반 자막
  - `강조 자막 · 교체가능` — 노랑→큰 흰색, 큰 글자 팝업 등 강조 패턴
  - `오버레이 교체 1…` — 순차 등장 카드/이미지를 실제 교체 가능한 영상 소재로 배치
  - `효과음 템플릿 · 교체가능` — 화면 이벤트에 동기화된 팝·임팩트·스파클 등 교체 슬롯
  - `제목 카드` 트랙 — 도입부 제목의 위치·크기·글자색·배경 박스색을 그대로 재현
  - `화면 효과 분석`, `효과음 후보` — 확인용 메모(숨김)

레퍼런스 자막의 위치·상대 크기·색·외곽선·배경 박스·등장 움직임을 프레임에서
측정하고, 화면의 플래시·블러·흔들림·줌·컷을 시간대별로 분류합니다. 일반 자막과
강조 자막은 겹치지 않게 분리합니다. 효과는 현재 Mac의 정상 CapCut 프로젝트와
리소스 캐시를 대조해 실제로 열리는 `팝 업`, `줌 2` 같은 애니메이션을 연결합니다.
따라서 영상 소재를 교체해도 해당 세그먼트의 효과가 유지됩니다.

흔들림·플래시·줌·블러처럼 실제 효과로 옮길 수 있는 후보 중 신뢰도 80% 이상인 것은
`화면 효과 재현` 트랙에 진짜 CapCut 영상 효과로 걸어둡니다. 열자마자 재생해보고
어울리지 않으면 그 조각만 지우면 됩니다. 하드컷은 효과가 아니라 자르는 지점이므로
자동 적용하지 않고 `화면 효과 분석` 트랙과 편집가이드에 시간만 남깁니다.

## 내 CapCut에 있는 효과만 사용합니다

효과와 자막 애니메이션은 **이 Mac의 CapCut이 이미 내려받은 것 중에서만** 고릅니다.
기존 CapCut 프로젝트와 리소스 캐시를 훑어 실제로 열리는 것만 쓰기 때문에,
초안에 `애니메이션 분실` 같은 빈 조각이 생기지 않습니다.

원하는 효과가 자동으로 안 걸린다면 CapCut에서 그 효과를 아무 프로젝트에나 한 번
써 보세요. 그 순간 리소스가 내려받아지고, 다음 실행부터 자동 적용 후보에 들어옵니다.
현재 쓸 수 있는 효과와 빠진 효과는 `편집가이드.md`에 항목별로 적힙니다.

완성된 MP4에는 원 제작자가 사용한 정확한 CapCut 프리셋명이나 폰트명이 저장되지
않습니다. 따라서 단정 대신 측정 근거, 신뢰도, 가장 가까운 CapCut 재현 후보를
함께 제공합니다.

## 사용법

1. 최초 한 번 `설치.command`를 실행합니다.
2. `릴스캡컷실행.command`를 더블클릭합니다.
3. 브라우저 화면에 공개 릴스 링크를 한 줄에 하나씩 넣습니다.
4. 원하면 `내 자막 원고` 칸에 새 문구를 넣습니다. 비워두면 받아쓴 원문으로 템플릿을 만듭니다.
5. 처리가 끝나면 결과 폴더와 CapCut이 열립니다.

화면 아래 `기획 분석 아카이브`에는 분석한 레퍼런스의 주제·작성자·시의성·후킹 점수가
누적됩니다. 각 작업 폴더의 `기획분석.md`에는 댓글에서 반복된 반응 근거와 재사용할
수 있는 기획 공식까지 저장됩니다.

## 같은 구조로 다시 만들기

아카이브의 `이 구조로 만들기`를 누르면 영상 분석을 다시 하지 않고 저장된 자막·효과·
컷·효과음 타이밍을 새 CapCut 초안으로 복제합니다. 새 프로젝트 이름과 내 자막 원고만
입력하면 되며, 원고를 비우면 기존 문구가 자리표시자로 유지됩니다. CapCut에서
`교체할 영상 · 템플릿` 트랙의 레퍼런스 영상만 내 영상으로 바꾸면 세그먼트 효과와
타이밍은 그대로 남습니다.

## 발행 성과 기록

아카이브의 `발행 결과 기록`에서 발행 링크·발행일·조회·좋아요·댓글·저장·공유·팔로우·
전환을 입력합니다. 조회수가 있으면 참여율·저장률·공유율·전환율을 자동 계산하고,
성과 회고와 함께 로컬 기획 아카이브 및 연결된 Obsidian 콘텐츠각 노트에 저장합니다.
같은 발행 링크를 다시 입력하면 기록을 중복 생성하지 않고 최신 수치로 갱신합니다.

Instagram 저장·공유·전환은 공개 페이지에서 확인할 수 없는 계정 인사이트이므로 자동으로
추측하지 않습니다. 본인 Instagram 인사이트에 표시된 실제 수치를 입력해야 합니다.

## Obsidian 세컨드 브레인 연결

이 Mac의 `~/Documents/Obsidian Vault`를 자동으로 찾습니다. 릴스 한 건을 처리할 때
기존 보관함의 분류법에 맞춰 다음 세 노트를 동시에 만들고 서로 링크합니다.

1. `10_SOURCE NOTES/Instagram Reels` — 출처, 3초 훅, 이탈방지, CTA, 댓글 근거,
   편집 문법이 담긴 원본 분석 노트
2. `20_INSIGHT CARDS/Instagram Reels` — 왜 사랑받았는지를 한 가지 재사용 원리로
   압축한 인사이트 카드
3. `30_CONTENT ANGLES/Instagram Reels` — 내 타깃·사례·CTA만 채우면 되는 발행 후보
   및 제작 체크리스트

`10_SOURCE NOTES/릴스 콘텐츠 인사이트 허브.md`에는 최근 레퍼런스, 후킹·시의성 점수,
반복해서 사랑받은 패턴, 아직 `idea` 상태인 콘텐츠각이 모입니다. `00_HOME.md`에도 허브
바로가기가 한 번만 추가됩니다. 같은 링크를 다시 분석하면 자동 생성 구간만 갱신하고
`내 메모`, `내 해석`, `제작 메모` 아래에 사용자가 쓴 내용은 보존합니다.

다른 보관함을 쓰고 싶으면 실행 전에 경로를 지정합니다.

```bash
export REELS_OBSIDIAN_VAULT="/absolute/path/to/My Vault"
```

옵시디언 적재를 잠시 끄려면 `REELS_OBSIDIAN_DISABLED=1`을 사용합니다. 옵시디언 저장이
실패해도 CapCut 초안과 로컬 결과는 그대로 보존됩니다.

CapCut에서는 다음 순서로 바꾸면 됩니다.

1. `교체할 영상 · 템플릿`의 원본 조각을 내 영상으로 교체합니다.
2. `말 자막`, `강조 자막 · 교체가능`, `제목 카드`의 문구를 다듬습니다.
3. `오버레이 교체` 소재를 내 이미지로 교체합니다.
4. `효과음 템플릿 · 교체가능`의 임시 소리를 원하는 효과음으로 교체하거나 음량만 조절합니다.

기본 결과 위치는 `~/Movies/ReelsToCapCut/YYYY-MM-DD/`입니다.

Instagram 다운로드가 막히면 Chrome 로그인 쿠키로 자동 재시도합니다. 그래도 실패하면
Chrome에서 Instagram에 로그인한 상태인지 확인하세요.

프로필 주소(`instagram.com/계정이름/`)는 영상 한 건을 특정하지 못하므로 사용할 수
없습니다. 프로필에서 분석할 릴스를 연 뒤 **공유 → 링크 복사**로 받은
`instagram.com/reel/릴스번호/` 주소를 넣어야 합니다. 웹 화면과 서버가 모두 프로필
주소를 미리 감지해 긴 다운로드 오류 대신 올바른 링크 안내를 보여줍니다.

화면 상단의 `기획 인사이트 찾기`에서는 아카이브를 다음 조건으로 조합해 검색하며
한 번에 최근 10개까지 표시합니다.

- 시의성 주제: 주제, 키워드, 작성자, 시의성 신호 통합 검색
- 3초 후킹: 트렌드 선언형, 시각 증거형, 질문·오픈루프형, 결론 선공개형
- 발행 목적: 전환·판매, 참여·댓글, 저장·재방문, 팔로워 성장, 행동 실행, 인지·신뢰
- 인사이트: 댓글과 본문에서 추출한 사랑받은 포인트

하단 `CapCut 작업 보관함`에는 앱을 재실행해도 기획 아카이브를 기준으로 완료된 작업의
결과 저장 경로와 CapCut 프로젝트명, 결과 폴더·CapCut·Obsidian 바로가기가 다시 표시됩니다.

## 개인정보와 안전

- 영상·음성·자막은 외부 AI API로 보내지 않습니다. Whisper와 OCR은 Mac에서 실행합니다.
- 서버는 `127.0.0.1`에만 열립니다.
- 기존 CapCut 프로젝트는 읽기만 하며 새 프로젝트 폴더만 만듭니다.
- 결과 폴더의 MP4를 CapCut 초안이 참조하므로 결과 폴더를 삭제하면 초안이 깨집니다.
- 공개 릴스의 구조 벤치마킹 용도로 사용하고 원본을 재배포하지 마세요.

## 개발 검증

```bash
.venv/bin/python -m unittest discover -s tests -v
```

종단간 샘플 검증:

```bash
REELS_CAPCUT_AUTO_OPEN=0 REELS_CAPCUT_NOTIFY=0 \
  .venv/bin/python -m reels_to_capcut.cli /absolute/path/sample.mp4 \
  --text "내 영상에 넣을 새 자막 원고"
```
