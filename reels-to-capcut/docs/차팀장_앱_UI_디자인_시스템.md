# 차팀장 앱 UI 디자인 시스템

릴스→CapCut 앱처럼 반복해서 사용하는 도구 화면에 적용하는 기준이다. 강의 캠페인·랜딩페이지의 입체 CTA 규칙과 달리, 앱 화면에서는 빠른 인지와 반복 조작을 위해 평면형 컨트롤을 사용한다.

## 참고 원칙

- 컬리 앱의 주행동은 그림자 없는 단색 채움으로 표시한다.
- 보조 행동은 동일한 높이를 유지하고 흰 배경과 얇은 선으로 위계를 낮춘다.
- 두 행동이 함께 있을 때 버튼 크기를 다르게 하지 않고 색과 문구로 우선순위를 구분한다.
- 퀵 메뉴와 아이콘은 간결하고 직관적으로 만들며 장식 효과를 반복하지 않는다.

## 앱 컨트롤 토큰

| 용도 | 값 |
|---|---|
| 주행동 배경 | `#FF5A45` |
| 주행동 글자 | `#FFFFFF` |
| 기본 글자 | `#17191F` |
| 보조 글자 | `#6B6862` |
| 컨트롤 선 | `#D8D2CA` |
| 호버 배경 | `#F5F1E8` |
| 선택 배경 | `#FFECE9` |
| 기본 반경 | `9px` |
| 버튼 높이 | 기본 `46px`, 밀집 영역 `40px` |
| 버튼 라벨 | Paperlogy `14px / 700` |
| 포커스 링 | 코랄 16% 투명도, `3px` |

## 버튼 위계

1. `Primary`: 코랄 채움. 화면당 한 가지 주행동에 사용한다.
2. `Strong secondary`: 차콜 채움. 파일 열기처럼 다음 작업으로 이동하는 행동에 사용한다.
3. `Secondary`: 흰 배경과 1px 뉴트럴 선. 취소·보조 열기에 사용한다.
4. `Text action`: 배경과 선 없이 문장 흐름 안의 이동에 사용한다.

## 상태 규칙

- Hover: 색 또는 배경만 가볍게 바꾸며 위치를 띄우지 않는다.
- Pressed: `scale(.98)`만 사용한다.
- Focus: 코랄 포커스 링을 표시한다.
- Disabled: 투명도 `42%`, 포인터 동작을 제거한다.
- 앱 버튼에는 검은 오프셋 그림자와 1.5px 이상의 검은 테두리를 사용하지 않는다.

## 관련 컨트롤

- 검색창과 셀렉트는 1px 뉴트럴 선, 포커스 시 코랄 선을 사용한다.
- 필터 칩은 기본 흰색, 선택 시 연한 코랄 배경과 코랄 글자를 사용한다.
- 모바일 중앙 생성 버튼은 평면 코랄 원형으로 사용하고 약한 확산 그림자만 허용한다.
- 브랜드 마크, 토스트, 점수 타일도 버튼처럼 보이는 검은 오프셋 그림자를 사용하지 않는다.
